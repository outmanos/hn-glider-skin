# HN Glider Skin

Userscript that reskins **Hacker News** with a modern, Material look: card-based rows, clean typography, upvote/comment counts as stat chips, light/dark/auto theme toggle and an data export function.

Stylistically inspired by the [Glider Android app](https://github.com/mosc/glider).

## Installation

Install from here:
https://greasyfork.org/en/scripts/603152-hn-glider-skin

Note that this requires a userscript extension (I recommend [violentmonkey](https://github.com/violentmonkey/violentmonkey) for Chromium-based browsers (Brave, Google Chrome, Microsoft Edge) and [greasemonkey](https://github.com/greasemonkey/greasemonkey) for Firefox)
