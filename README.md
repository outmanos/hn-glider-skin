# HN Glider Skin

Userscript that reskins Hacker News with a modern, Glider-inspired Material look: card-based rows, clean typography, upvote/comment counts as stat chips, light/dark/auto theme toggle and an data export function.

Inspired by the [Glider Android app](https://github.com/mosc/glider)
